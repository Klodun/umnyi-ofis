# Чек-лист по плану офиса

Что уже есть на плане (`docs/plan-office.plan`):

- рабочая зона со столами (19), стульями (27), розетками (42);
- переговорная (стол, стулья, флипчарт);
- санузел, кухня, зона ожидания;
- серверная: сетевой шкаф, три сервера;
- датчик температуры, датчики влажности, умная колонка, робот-пылесос.

## Что добавить в remplanner (5 минут)

1. Подписи зон (инструмент «Текст»):
   - `Рабочая зона` — большое открытое помещение;
   - `Переговорная` — комната с длинным столом;
   - `Коридор` — проход между зонами;
   - `Серверная` — помещение со шкафом и серверами;
   - `Входная зона` — у входной двери.
2. Подписать вентилятор в серверной: `FAN` (объект «Осевой вентилятор» уже есть — рядом поставить подпись).
3. Добавить ПК на рабочие места (каталог «Компьютеры» → монитор/системный блок) — хотя бы 5–6 штук.
4. Довести IoT-устройства до 5–7 разных категорий. Сейчас есть: датчик температуры,
   датчик влажности, умная колонка, робот-пылесос. Добавить, например:
   - умная розетка (категория «Электрика» → умная розетка);
   - умная лампа / светильник с управлением;
   - умный чайник (кухня) или климатический датчик CO₂.
5. Сохранить план и заменить файл в репозитории: `docs/plan-office.plan`.

## Проверка

- файл `.plan` открывается в https://remplanner.ru/planner/;
- на плане читаются все пять зон и подписи TEMP, FAN, HUM;
- количество IoT-устройств — не меньше пяти, категории разные.
