# Таблица адресации и портов

Маска всех подсетей — **/26** (255.255.255.192).

## Адресация

| VLAN | Подсеть | Хост | IP-адрес хоста | Шлюз |
|---|---|---|---|---|
| 30 | 192.168.30.0/26 | Cisco RTR | 192.168.30.1 | — |
| 30 | 192.168.30.0/26 | WIN | 192.168.30.10 | 192.168.30.1 |
| 40 | 192.168.40.0/26 | Cisco RTR | 192.168.40.1 | — |
| 40 | 192.168.40.0/26 | CTRL | 192.168.40.10 | 192.168.40.1 |
| 40 | 192.168.40.0/26 | MON | 192.168.40.11 | 192.168.40.1 |
| 40 | 192.168.40.0/26 | DB | 192.168.40.12 | 192.168.40.1 |
| 50 | 192.168.50.0/26 | Cisco RTR | 192.168.50.1 | — |
| 50 | 192.168.50.0/26 | IOT | 192.168.50.10 | 192.168.50.1 |
| 99 | 192.168.99.0/26 | Cisco SW (управление) | 192.168.99.2 | 192.168.99.1 |

Подсеть VLAN 99 заложена в план для управляемого коммутатора; в текущей сборке GNS3 коммутатор
неуправляемый (Ethernet switch), поэтому VLAN 99 не используется.

## Порты коммутатора

| Порт | Устройство | VLAN | Режим |
|---|---|---|---|
| Ethernet1 | WIN | 30 | access |
| Ethernet2 | CTRL | 40 | access |
| Ethernet3 | MON | 40 | access |
| Ethernet4 | DB | 40 | access |
| Ethernet5 | IOT | 50 | access |
| Ethernet0 | REDOS8-5 | 30, 40, 50 | trunk (dot1q) |

## Порты сервисов

| Порт | Где | Назначение |
|---|---|---|
| 22/tcp | CTRL, MON, DB, IOT | SSH |
| 8080/tcp | CTRL | ПР №3 — Nginx (docker run / docker compose), после проверки освобождён; ПР №4 — приёмник показаний датчиков (`/health`, `POST /api/readings`); ПР №5 — приёмник v2, дополнительно `POST /api/actuators` |
| 1880/tcp | IOT | ПР №4 — Node-RED (редактор потоков, `http://192.168.50.10:1880`) |
| 3389/tcp | WIN | RDP |
