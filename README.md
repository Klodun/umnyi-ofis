# Умный офис

Учебный проект по ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными
интегрированными системами», МДК 03.01.

**Номер в журнале:** 1
**Группа:** 54-15
**Студент:** Анфилатов Ярослав Дмитриевич

## Цель проекта

Показать заказчику работающий виртуальный прототип «умного офиса»: в помещении есть рабочая
зона, переговорная, коридор, серверная и входная зона. В серверной при повышении температуры
автоматически включается охлаждение (вентилятор), сотрудник с рабочего места (WIN) может
следить за показаниями датчиков и управлять вентилятором вручную. Датчики температуры
и влажности имитируются в Node-RED на узле IOT-01 (ПР №4); автоматика вентилятора —
следующий этап проекта.

на них без изменения адресации.

## Виртуальные датчики (ПР №4)

Два виртуальных датчика живут в Node-RED на IOT-01 и каждые 5 секунд отправляют показание
на приёмник в CTRL-01:

| Датчик | Зона | Единица | Диапазон значения |
|---|---|---|---|
| TEMP-01 | server_room | °C | 18…26 |
| HUM-01 | work_area | % | 35…60 |

Цепочка в Node-RED: `inject` (каждые 5 с) → `change` (сборка объекта `msg.reading`) →
`http request` (`POST http://192.168.40.10:8080/api/readings`) → `debug`.
Подробности запуска и проверки — в `practice4/README.md`.

## Вентилятор FAN-01 (ПР №5)

Вторая вкладка Node-RED — «Вентилятор FAN-01». Температура задаётся вручную в узле `inject`
«Температура, °C» (число, Done, Deploy, клик по квадратику), узел `switch` сравнивает её
с порогом **30 °C**; для каждого состояния свой узел `change` собирает объект `msg.fan`
(`state`, `actuator_id` = `FAN-01`, `zone` = `server_room`, `mode` = `auto`, `timestamp`),
который отправляется POST-запросом на `http://192.168.40.10:8080/api/actuators`.

Приёмник обновлён до версии 2 (раздаточные материалы к ПР №5): `GET /health` отдаёт
`{"status":"ok","version":2,"endpoints":["/api/readings","/api/actuators"]}`.
Подробности — в `practice5/README.md`.

## Как проверял

* ПР №1 — план и схема открываются в remplanner.ru и draw.io; таблица адресации сведена в `docs/addresses.md`.
* ПР №2 — с WIN-01 проходят ping до IOT-01 и трёх серверов РЕД ОС (0 % потерь), с IOT-01 — до CTRL-01, MON-01 и DB-01.
  Скриншоты: `docs/screens/pr2-win-ping.png`, `evidence/`.
* ПР №3 — Docker и Docker Compose установлены на CTRL-01, DB-01, IOT-01; Nginx отвечает `HTTP/1.1 200 OK`
  с порта 8080 при запуске и через `docker run`, и через `docker compose`; после проверки порт освобождён.
* ПР №4 — приёмник на CTRL-01 отвечает `{"status":"ok"}` на `/health`; Node-RED на IOT-01 открывается
  с WIN-01 по `http://192.168.50.10:1880`; оба датчика присылают показания каждые 5 секунд, приёмник
  пишет их в журнал (100 записей за ~4 минуты непрерывной работы, формат ответа `{"status":"ok","sensor_id":…,"value":…}`).
  Доказательства: `evidence4/01-ctrl-check.txt`, `evidence4/02-receiver-log.txt`, `evidence4/03-iot-check.txt`.
* ПР №5 — приёмник v2 на CTRL-01 отвечает на `/api/actuators`; при температуре выше 30 °C узел
  `switch` отправляет `fan.state = ON`, ниже — `OFF`; в журнале приёмника видны оба состояния
  с интервалом 5 секунд. Доказательства: `evidence5/01-health.txt`, `evidence5/02-actuator-log.txt`.
