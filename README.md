# Умный офис

Учебный проект по ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными
интегрированными системами», МДК 03.01.

**Номер в журнале:** 1
**Группа:** 54-15
**Студент:** Анфилатов Ярослав Дмитриевич

## Цель проекта

Показать заказчику работающий виртуальный прототип «умного офиса»: в помещении есть рабочая
зона, переговорная, коридор, серверная и входная зона. В серверной при повышении температуры
автоматически включается охлаждение (вентилятор), сотрудник с рабочего места (WIN) может
следить за показаниями датчиков и управлять вентилятором вручную. Датчики и вентилятор
имитируются в Node-RED на узле IOT-01.

## Как проверял

* ПР №1 — план и схема открываются в remplanner.ru и draw.io; таблица адресации сведена в `docs/addresses.md`.
* ПР №2 — с WIN-01 проходят ping до IOT-01 и трёх серверов РЕД ОС (0 % потерь), с IOT-01 — до CTRL-01, MON-01 и DB-01.
  Скриншоты: `docs/screens/pr2-win-ping.png`, `evidence/`.
* ПР №3 — Docker и Docker Compose установлены на CTRL-01, DB-01, IOT-01; Nginx отвечает `HTTP/1.1 200 OK`
  с порта 8080 при запуске и через `docker run`, и через `docker compose`; после проверки порт освобождён.
